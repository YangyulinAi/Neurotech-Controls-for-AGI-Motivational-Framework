# IIT 集成钩子开发指南（Replit 专用）

> **目的**：在不影响现有情绪‑BCI 主干功能的前提下，为项目加入一个“**Integrated Information Theory (IIT) Φ 计算接口**”。该接口默认轻量运行（返回占位值），同时允许研究者一键启用真实 Φ 计算，以支撑未来的意识/复杂度研究。

---

## 1. 目标与约束

| 要点      | 说明                                                                    |
| ------- | --------------------------------------------------------------------- |
| **兼容性** | 默认 **不安装重型依赖**（如 PyPhi）。启用 `--compute_phi` 时才加载；否则返回零张量，不影响性能。        |
| **可插拔** | Φ 计算逻辑封装在 `src/phi_estimator.py`；训练、推理脚本仅通过 `phi_est.compute()` 调用。   |
| **灵活性** | 支持多种 Φ 近似方法：`"mock"`, `"IIT3.0"`, `"IIT4.0_light"`；可限制通道数、窗口长度、二值化阈值。 |
| **可扩展** | 未来可在同接口下接入 Causal Density、Neural Complexity 等指标。                      |

---

## 2. 依赖管理

### 2.1 可选依赖文件

在根目录新增 `requirements_phi.txt`：

```txt
pyphi~=1.2
networkx~=3.0
```

> ⚠️ **Replit CPU** 容易 OOM；若仅做占位或单元测试，可暂不安装。在线推理环境如果启用 Φ，建议转移到外部 GPU/CPU 服务器。

### 2.2 安装方式

* **默认运行（占位）**：`pip install -r requirements.txt`  ➜ 不含 PyPhi。
* **启用 Φ 计算**：

  ```bash
  pip install -r requirements.txt -r requirements_phi.txt
  ```

## 4. 代码实现细节

### 4.1 `src/phi_estimator.py`

```python
import torch
from typing import Literal, Optional

class PhiEstimator:
    """Integrated Information Φ 计算器；默认占位实现。"""

    def __init__(
        self,
        method: Literal["mock", "IIT3.0", "IIT4.0_light"] = "mock",
        max_channels: int = 8,
        tau: int = 1,
        bin_method: Literal["median", "threshold", "multi"] = "median",
        **kwargs,
    ):
        self.method = method
        self.max_channels = max_channels
        self.tau = tau
        self.bin_method = bin_method
        self.backend_ready = False

        if method != "mock":
            # 延迟导入，避免无脑安装重型库
            try:
                import pyphi  # noqa: F401
                self.backend_ready = True
            except ImportError:
                print("[PhiEstimator] PyPhi 未安装，自动回退 mock Φ=0")
                self.method = "mock"

    def _binarize(self, eeg_slice: torch.Tensor) -> torch.Tensor:
        """(channels, time) → (channels, time) 二值化 / 多阶化"""
        if self.bin_method == "median":
            med = eeg_slice.median(dim=1, keepdim=True).values
            return (eeg_slice > med).int()
        # TODO: add other methods
        return (eeg_slice > 0).int()

    def compute(self, eeg_batch: torch.Tensor) -> torch.Tensor:
        """
        Args:
            eeg_batch: (batch, channels, time)
        Returns:
            Φ values: (batch,)
        """
        if self.method == "mock":
            return torch.zeros(eeg_batch.size(0))

        # NOTE: 真实 Φ 计算仅示例，计算量指数级，请小心通道数
        import pyphi
        phis = []
        for sample in eeg_batch:
            # 1. 取前 N 通道
            sample = sample[: self.max_channels]
            # 2. 二值化
            bin_state = self._binarize(sample).numpy()
            # 3. 构建 PyPhi Network & subsystem
            net = pyphi.Network(bin_state)
            sub = pyphi.Subsystem(net, bin_state[:, -1])
            phis.append(pyphi.compute.big_phi(sub, tau=self.tau))
        return torch.tensor(phis)
```

> **安全阀**：当 `method=="mock"` 或 `PyPhi` 缺失时，函数返回全零张量，确保主干代码稳定。

### 4.2 CLI & 配置

* **训练脚本** `train_labeled.py` 增加参数：

  ```bash
  --compute_phi true --phi_method IIT3.0 --phi_max_channels 6
  ```
* **配置文件** `configs/phi.yaml` 示例：

  ```yaml
  compute_phi: true
  phi_method: "IIT4.0_light"
  max_channels: 6
  tau: 1
  bin_method: "median"
  ```
* 在主训练循环里：

  ```python
  if cfg.compute_phi:
      phi_vals = phi_est.compute(raw_eeg_window)  # (batch,)
      logger.add_scalar("phi", phi_vals.mean().item(), global_step)
  ```

### 4.3 推理服务 `main.py`

* 启动参数：`--publish_phi true`。
* 发布格式：

  ```json
  {
    "valence": 0.12,
    "arousal": 0.44,
    "phi": 0.03,
    "ts": 1722748600.123
  }
  ```

### 4.4 异步计算（可选高级）

* 对计算量大的 Φ：

  1. 使用 `concurrent.futures.ThreadPoolExecutor` 将 `phi_est.compute()` 放在线程池。
  2. 主线程先返回情绪预测；待 Future 完成后再补发 “phi\_update” 消息。

from src.phi_estimator import PhiEstimator

def test_mock_phi():

## 7. FAQ

| 问题                    | 答案                                 |
| --------------------- | ---------------------------------- |
| Replit 裸机算得动 PyPhi 吗？ | 小规模 (<6 通道, 1 秒窗) 尚可；大规模建议转移到服务器。  |
| 不想安装 PyPhi 但又想看字段？    | 默认 `method="mock"` 即可，字段存在，值为 0。   |
| Φ 计算为何需要二值化？          | PyPhi 目前仅支持离散状态空间，通常使用 0/1 或多阶离散化。 |
