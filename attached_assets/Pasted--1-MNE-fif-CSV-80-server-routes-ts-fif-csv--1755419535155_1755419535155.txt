2）分析脚本：支持 MNE Epochs

文件 tests/analyze_file_onnx.py 的“加载任意格式”函数内（已有 .set/.fif/.csv 分支），给 .fif 补一个 Epochs 回退（伪代码示意，直接粘进去即可）：

elif ext == '.fif':
    try:
        raw = mne.io.read_raw_fif(filepath, preload=True)
        mode = 'raw'
    except Exception:
        # 尝试按 Epochs 读取（-epo.fif）
        epochs = mne.read_epochs(filepath, preload=True, verbose=False)
        mode = 'epochs'
        # 统一到 raw-like：将 epochs 堆叠为 (n_channels, n_epochs*n_times)
        data_3d = epochs.get_data()               # (n_epochs, n_channels, n_times)
        data = data_3d.transpose(1,0,2).reshape(data_3d.shape[1], -1, order='C')
        info = mne.create_info(ch_names=epochs.ch_names, sfreq=epochs.info['sfreq'], ch_types='eeg')
        raw = mne.io.RawArray(data, info)
    print(f"DEBUG: Loaded FIF ({mode}) with {len(raw.ch_names)} ch, {raw.n_times} samples")


这样：Raw 与 Epochs 都转成 RawArray，后续你的滑窗/特征/ONNX 推理无需改动。
